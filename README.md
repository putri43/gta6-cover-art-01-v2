Vice City Cover Studio — an offline web app that turns your photos and a caption into GTA-style poster art: multi-panel covers, bold sunset-gradient lettering, Vice City sunset and neon colour grades, exported as a PNG to share.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network. Pick up to four photos, choose one of six layouts (Hero + 3, Four Panel, Nine Panel, Full Bleed, Snapshots, Diagonal Split), one of five grades (Vice Sunset, Neon Nights, Palm Gold, Ocean Drive, Mono Noir), crop and position each panel, write your title and subtitle, and export 1080 x 1080, 1080 x 1350 or 1920 x 1080 PNGs — one size, or all three at once. Undo/redo included. Everything is drawn on canvas on your machine; photos never leave the browser, and all artwork is original — no Rockstar logos, artwork or fonts.
